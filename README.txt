BİZİM KONAK — iPhone PWA

Bu paket doğrudan statik site olarak yayınlanabilir.

En hızlı kullanım:
1. Klasördeki tüm dosyaları Netlify Drop, Cloudflare Pages, GitHub Pages veya benzeri bir statik site hizmetine yükleyin.
2. Oluşan HTTPS adresini iPhone'da Safari ile açın.
3. Paylaş > Ana Ekrana Ekle > Ekle.
4. Bizim Konak, ana ekranda uygulama gibi açılır.

Veriler cihazın tarayıcısındaki localStorage alanına kaydolur.
Ayarlar > Tam Yedek Al ile düzenli JSON yedeği alın.
Ayarlar > Verileri CSV Olarak Dışa Aktar ile Excel'de açılabilen dosya alın.

İlk sürüm özellikleri:
- Gelir ekleme (nakit/kart)
- Gider ekleme (kira, fatura, personel, tedarikçi vb.)
- Günlük ve aylık ciro, gider, net kâr
- Kâr marjı
- Son 7 gün grafiği
- Kasadaki nakit
- Veresiye takibi
- CSV dışa aktarım / JSON yedek
- Ana ekrana eklenebilir PWA

Hesap:
Ciro = tüm gelirler
Net Kâr = toplam gelir - toplam gider
Kasadaki Nakit = başlangıç kasa + nakit gelir - nakit gider
